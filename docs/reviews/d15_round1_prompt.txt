Requirements (D-15, the contract to validate against):
R1. A known binary extension (executables/libraries, archives, images, audio/video, office documents, databases/models, fonts) is refused without reading the file, case-insensitively.
R2. A file without an extension (README) and scripts (.bat, .ps1, .sh) open.
R3. A refused file opens no tab, shows the status-bar message "Cannot open '<name>' — binary file", and keeps the tree selection.
R4. The check applies to every open path: tree click, double click, Enter, Ctrl+Enter (open to side), right-click "Open as Viewer" / "Open as Editor", and File > Open File.
R5. A CP949 text file opens read-only in Viewer mode with correctly decoded text and can never switch to Editor or be saved (saving would re-encode it as UTF-8). The status-bar mode toggle refuses with "CP949 file — read-only".
R6. The check is asynchronous; when requests overlap, only the latest request opens a tab.
R7. Both hosts (Electron fs-ops.cjs and pywebview main.py) must give the same verdict for the same bytes.
