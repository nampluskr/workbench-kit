## 3. 지적과 처리

### R1-1 (Major) — Zen이 켜진 아이콘은 화면에 보이는 순간이 없다

- **지적**: Zen을 켜면 아이콘이 켜진 글리프로 바뀌지만, 같은 순간 상단 바 전체가 감춰진다.
  `Escape`로 상단 바가 돌아올 때는 이미 꺼진 글리프다. 검사는 감춰진 요소의 `::before`를 읽어서
  이것을 못 잡는다.
- **판단**: **사실이다.** 다만 코드 결함이 아니라 두 요구가 맞물린 결과다. v0.1 `FR-F5`(Zen은
  상단 바를 감춘다)가 대체 목록에 없으므로 그대로 성립해야 하고, v0.2 `FR-C2`는 Zen 상태를
  아이콘으로 보이라고 한다. 둘을 동시에 화면에서 만족시키는 배치는 없다.
- **처리**: **수정하지 않는다.** 명세 충돌이라 에이전트가 한쪽을 고를 수 없다. 사람 확인 사항으로
  올린다. 지금 구현은 켜진 상태를 `aria-pressed`와 글리프에 계속 반영하므로, 상단 바가 Zen
  중에도 보이도록 결정이 바뀌면 추가 작업 없이 맞는다.

### R1-2 (Major) — 공개 앱 API로 세로 띠 기본 구성을 통째로 바꿀 수 있다

- **지적**: `setActivityBarTopItems()` · `setActivityBarBottomItems()`가 배열을 교체하므로, 앱이
  부르면 상단 바 · 하단 바 토글이 사라지거나 Zen · 테마 · 분할 항목이 다시 들어올 수 있다.
- **판단**: 동작 설명은 맞다. 그러나 그것이 v0.1 `FR-N12`(앱이 공통 코어 diff 0줄로 세로 띠
  항목을 **바꾼다**)의 계약이고, 이 요구는 대체 목록에 없다. `FR-C4` ~ `FR-C6`은 **껍데기가 놓는
  기본 구성**에 대한 요구로 읽는 것이 두 요구를 함께 성립시키는 유일한 해석이다.
- **처리**: **수정하지 않는다.** 앱이 교체하는 경로를 막으면 `FR-N12` 회귀다.

### R1-3 (Major) — Git 메타데이터가 없는 사본을 빌드하면 날짜가 `unknown`이 된다

- **지적**: 소스 압축본처럼 `.git`이 없으면 `git log`가 실패하고, 제목 줄이
  `Workbench-Kit v0.1 (unknown) - …`가 되어 형식이 깨진다.
- **처리**: **수정했다.** `vite.config.ts`가 `git log`에 실패하면 `src/` 아래 가장 최근에 수정된
  파일의 날짜를 `YYYY-MM-DD`로 쓴다. 그것마저 없을 때만 `unknown`이다. Git이 있는 저장소에서는
  동작이 그대로라 기존 `V2P3-FR-C8`이 계속 판정한다.

### R1-4 (Major) — 창을 아주 좁히면 프로그램 정보가 잘리고 끌기 구간이 0폭이 된다

- **지적**: 두 갈래 모두 최소 폭이 없어, 제목 줄 요소 폭의 합보다 창을 좁히면 정보가 말줄임으로
  잘리고 빈 끌기 구간이 사라진다.
- **판단**: 사실이지만 v0.2 요구는 **보통 창 폭**에서의 배치를 판정한다. 최소 창 폭은 어느
  요구에도 없고, 이를 두 갈래 창 생성 옵션으로 새로 정하는 것은 이번 Phase 범위 밖이다.
  잘리는 쪽을 말줄임으로 둔 것은 창 제어 버튼이 밀려나지 않게 하려는 의도다.
- **처리**: **수정하지 않는다.** 다음 버전 후보로 기록한다.

## 4. 결과

Critical 0건. Major 4건 중 1건 수정(R1-3), 3건은 위 근거로 수정하지 않았다(R1-1은 사람 확인
사항). Phase 3을 닫는다.
