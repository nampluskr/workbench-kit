## 유효하지 않은 지적과 반박 근거

**#3 (2회차 Minor, Explorer 펼침·선택·스크롤 상태 미검증)** — 보류, 근거:

- `docs/current/PLAN.md`를 보면 "각 폴더 탭이 Explorer의 펼침 상태 · 선택 항목 · 스크롤
  위치를 독립적으로 갖는다"는 **Phase 4**의 완료 조건이다(`D-5`). Phase 3는 아직 그
  상태 자체를 도입하지 않는다 — `FolderTab`에는 그런 필드가 없다.
- Phase 3의 "보존" 완료 조건은 "레일을 감췄다 다시 보여도 등록 폴더·탭 순서·별칭·활성
  상태·각 폴더의 Explorer 상태가 그대로다"인데, 이번 회차에서 검증한 탭 목록·별칭·
  활성 탭이 **현재 실제로 존재하는 상태의 전부**다. 없는 필드를 검증할 수는 없다.
  Phase 4가 펼침·선택·스크롤을 도입하면 그 때 이 보존 검사에 추가해야 한다.

## 미해결 · 남은 위험

- 레일 표시 상태의 "저장 안 됨"은 실제 프로세스 재시작이 아니라 `localStorage` 키
  이름 추정으로만 확인했다 — Phase 1의 "마지막 폴더 복원 없음" 검증과 같은 한계다.
  Phase 4가 실제 재시작 흐름을 검증하는 인프라를 만들 때 이 항목도 같은 방식으로
  다시 확인하는 것이 좋다.
- Phase 4(폴더별 Explorer 상태)가 이 Phase의 토글과 상호작용하는지(예: 레일을 감춘
  채 재시작 복원이 일어나는 경우)는 아직 검증 범위 밖이다.
