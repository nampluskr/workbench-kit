Major/Minor fixes made this round:
6. Menu tests (N6/N7/N8) now compare visible label text (not just ids), and N6 counts
   app-added rows separately instead of silently absorbing them. N5 was split into
   "0 permanent menu bar" (checked before the menu ever opens) and "exactly 3 groups"
   (checked once opened).
7. Icon-theme test (Q1A) now tracks one row's data-id explicitly across all 3
   before/after/round-trip reads, instead of re-querying ".tree-icon" generically.
8. Zen test (F5) now also checks the tab/editor area (#main-area) stays visible and
   window.outerWidth/outerHeight are unchanged; F6 now checks all 4 chrome pieces are
   restored (not just the titlebar).
9. NFR-4 checks broadened: now require the real library's own entry point/factory to
   actually be called (createDockview(), monaco.editor.create()), not just imported;
   broadened the reimplementation-class-name blocklist; extended the inline-SVG scan to
   vscode-icons.ts (was seti.ts only) and added an asset-count check for vscode-icons.
10. checklist.md now has a scripts/verify-phase7.mjs section (was missing entirely).
11. License/About checks now verify actual license-family content per file (MIT vs CC
    BY 4.0 vs CC BY-SA, via regex against real file bodies) instead of only filename
    existence, and cross-check About's copyright-holder strings against
    licenses/README.md instead of independently re-typed values that could drift.
12. F1 now checks computed display + a real increase in the editor area's rendered
    width, not just a `.hidden` class name; F2/F3/F4 use computed display instead of
    class-name checks; N9 now checks a real "workbench-kit vX.Y.Z · <branch>" string
    matches the actually-running host, plus a new N9-PATH check that selecting a real
    tree row updates the status bar's path zone to that row's real target; M4 now
    tracks one persistent icon's glyph class across all 3 themes and requires its
    computed color to actually differ.
