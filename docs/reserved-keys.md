# RESERVED-KEYS — 껍데기가 먼저 가져가는 키 (FR-R1 · FR-R1a · D-19)

> 이 문서가 유일한 예약 키 목록이다(FR-R1). 여기 없는 키는 전부 앱(탭 안의 보기) 몫이다.
> 포커스가 탭 안에 있을 때 이 목록에 없는 키를 누르면 껍데기 쪽 처리 기록이 0건이고
> 그 키는 탭의 보기가 받는다(FR-I6).

## 1. 전역 — 포커스와 무관하게 껍데기가 가져간다

| 키 | 동작 | 근거 |
| --- | --- | --- |
| `Ctrl+O` | 폴더 열기 | FR-A1, D-16 |
| `Ctrl+W` | 활성 탭 닫기 | FR-N6b |
| `Ctrl+\` | 좌우 스플릿 | FR-D1 |
| `F10` | 햄버거 메뉴 열기/닫기 | FR-N5, D-7 |
| `F11` | Zen 모드 전환 | D-12 |
| `Escape` | 열린 메뉴를 닫거나(메뉴가 열려 있을 때), Zen 모드를 빠져나온다(Zen일 때) | D-12 |

## 2. 메뉴가 열려 있을 때만

| 키 | 동작 |
| --- | --- |
| `ArrowUp` / `ArrowDown` | 항목 사이 이동 |
| `ArrowLeft` / `ArrowRight` | File · View · Help 사이 이동 |
| `Enter` | 포커스된 항목 실행 |
| `Escape` | 메뉴 닫기 |

## 2b. 우클릭 메뉴가 열려 있을 때만 (WK-030, D-22)

| 키 | 동작 |
| --- | --- |
| `ArrowUp` / `ArrowDown` | 항목 사이 이동 |
| `Enter` | 포커스된 항목 실행 후 닫기 |
| `Escape` | 메뉴 닫기 |

우클릭 메뉴와 햄버거 메뉴는 상호 배타적이다 — 하나가 열리면 다른 하나는 자동으로
닫힌다(`workbench:menu-open` · `workbench:contextmenu-open` 이벤트로 조율).

## 3. 트리에 포커스가 있을 때만 (FR-A2 ~ FR-A19, D-9)

| 키 | 동작 |
| --- | --- |
| `ArrowUp` / `ArrowDown` | 포커스 1칸 이동 |
| `ArrowRight` | 접힌 폴더 펼침 / 펼쳐진 폴더 첫 자식으로 이동 |
| `ArrowLeft` | 펼친 폴더 접기 / 접힌 폴더·리프는 부모로 이동 |
| `Ctrl+ArrowLeft` | 모두 접기 |
| `Space` | 토글(펼침/접힘) |
| `Enter` | 선택한 항목 열기 (FR-A6) |
| `Ctrl+Enter` | 옆 칸에 열기 (FR-A14) |
| `Ctrl+Shift+Enter` | 선택 토글 |
| `Home` / `End` | 처음/끝으로 이동 |
| `PageUp` / `PageDown` | 화면 단위 이동 |
| `Shift+ArrowUp` / `Shift+ArrowDown` | 연속 범위 선택 |
| `Ctrl+ArrowUp` / `Ctrl+ArrowDown` | 포커스 불변 스크롤 |
| `Ctrl+A` | 전체 선택 |
| `Escape` | 선택 해제 (또는 찾기 위젯이 열려 있으면 찾기 위젯 닫기) |
| `F3` / `Ctrl+Alt+F` | 트리 안에서 찾기 열기 |

## 4. 껍데기가 **가져가지 않는다** — 흔히 오해하는 여섯 (FR-R1a)

탭에 포커스가 있을 때 아래 여섯은 껍데기가 손대지 않고 그대로 탭의 보기가 받는다.
저장·이름 바꾸기·삭제·되돌리기·복사·붙이기는 전부 리소스 종류를 아는 앱의 일이다
(D-18 · D-22 · D-30).

| 키 | 앱 몫 |
| --- | --- |
| `Ctrl+S` | 저장 |
| `F2` | 이름 바꾸기 |
| `Delete` | 삭제 |
| `Ctrl+Z` / `Ctrl+Y` | 되돌리기 / 다시하기 |
| `Ctrl+C` / `Ctrl+V` | 복사 / 붙이기 |

## 5. 마우스 없이 부르는 경로 (NFR-7)

메뉴·세로 띠·탭 줄의 명령은 각각 마우스 없이 실행하는 경로가 최소 1개 있다.

| 자리 | 경로 |
| --- | --- |
| 메뉴(File · View · Help) | `F10`으로 열고, 화살표 키로 항목을 옮기고, `Enter`로 실행한다 |
| 세로 띠 | 네이티브 `<button>`이라 `Tab`으로 포커스하고 `Enter`/`Space`로 누른다 |
| 탭 줄(Split Right · Split Down · New Tab) | 네이티브 `<button>`이라 `Tab`으로 포커스하고 `Enter`/`Space`로 누른다 |

이 경로들에 쓰이는 키는 전부 위 1 ~ 3절에 있다. 이 목록 밖의 키가 명령 실행에 쓰이는
경우는 없다.
