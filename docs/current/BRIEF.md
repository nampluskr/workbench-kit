# BRIEF — workbench-kit v0.3

## 1. 배경

이 문서는 여러 작업 폴더를 지속적으로 전환하며 사용할 수 있는 작업 폴더 전환 방식을
기획한다.

현재 Explorer는 한 번에 루트 폴더 하나만 표시한다. 다른 작업 폴더를 열면 기존
Explorer 루트가 교체되므로, 여러 프로젝트나 테스트 폴더를 오갈 때마다 앞서 보던
트리의 펼침 상태, 선택 위치, 스크롤 위치가 사라진다. 최근 폴더 목록은 경로를 다시
찾는 데에는 도움이 되지만, 지금 열어 두고 비교하는 작업 단위를 화면에 계속 남겨
두지는 못한다.

사용자는 Warp나 Tabby의 왼쪽 세로 탭처럼, 여러 작업 폴더를 한 창에서 눈에 보이게
보존하고 원하는 폴더로 즉시 전환하고 싶다. 다만 이 앱의 Activity Bar는 Explorer
표시 같은 전역 영역 제어를 맡고 있으므로, 폴더 목록으로 바꾸지 않는다.

## 2. 이번 버전에서 풀고 싶은 문제

**여러 작업 폴더를 세로 탭으로 등록하고, 하나의 Explorer에서 선택한 폴더를
전환한다.** Activity Bar 오른쪽에 별도의 폴더 탭 레일을 둔다. 사용자가 명시적으로
추가한 폴더만 탭이 되며, 탭에는 폴더 아이콘과 식별 가능한 이름이 보인다. 현재 활성
폴더 탭은 시각적으로 구별한다. 탭을 선택하면 Explorer는 그 폴더 하나의 트리만
표시한다. Activity Bar에서는 Explorer와 폴더 탭 레일을 각각 독립적으로 보이게 하거나
감출 수 있다.

**작업 폴더를 닫기 전까지 작업 맥락을 보존한다.** 폴더를 전환했다 돌아와도 각
폴더의 Explorer 펼침 상태, 선택 상태, 스크롤 위치가 돌아와야 한다. 앱을 다시
열어도 등록한 폴더 탭, 표시 순서, 표시 별칭, 마지막 활성 폴더와 Explorer 상태를
복원한다. 사라지거나 이동한 경로는 사용자가 조치할 수 있도록 탭을 남긴 채 오류로
알린다.

**Explorer 전환과 에디터 전환을 필요에 따라 고른다.** 어떤 작업에서는 Explorer만
바꾸고 현재 에디터 탭과 분할 화면을 그대로 유지해야 한다. 다른 작업에서는 폴더마다
독립된 에디터 탭과 분할 화면을 돌아가며 사용해야 한다. 사용자는 메뉴에서 두 방식을
전역적으로 선택할 수 있어야 한다. 폴더별 에디터 작업공간은 같은 실행 안에서만
살아 있으며, 재시작 뒤에는 빈 에디터로 시작한다.

## 3. 이전 버전에서 아쉬웠던 것

v0.2는 실제 사용 중 발견한 탭 수명, 선택·포커스 표시, 창 껍데기 배치, Explorer
표시, 테마와 표시 언어를 고쳐 쓰는 버전이었다. 이번 요구는 그 항목들의 시각 보정이
아니다. Explorer가 하나의 폴더를 교체하는 수명 모델을 여러 작업 폴더를 유지하고
전환하는 모델로 넓히는 별도 기능이다.

따라서 v0.2의 사용자 테스트에서 아직 재검증하지 않은 항목을 이 버전에 섞지 않는다.
v0.3은 폴더 탭과 그에 따른 Explorer·에디터 전환 규칙을 독립적으로 검증한다.

## 4. 하지 않을 것

- 여러 폴더의 루트를 하나의 Explorer 트리에 동시에 보이는 다중 루트 Explorer.
- 트리의 하위 폴더를 펼치거나 생성할 때마다 Activity Bar에 아이콘을 자동 추가하는
  방식.
- 사용자가 선택하지 않은 폴더의 자동 등록.
- 실제 파일 또는 폴더 생성, 삭제, 이동, 이름 변경 같은 파일시스템 작업.
- v0.2 사용자 테스트의 잔여 수정 요구를 함께 처리하는 일.
- 폴더별 에디터 탭과 분할 레이아웃을 앱 재시작 뒤까지 복원하는 일.

## 5. 완료 조건

사람이 Electron과 pywebview를 각각 실행해 아래를 모두 직접 확인했을 때 이 버전은
끝난다.

- 서로 다른 둘 이상의 폴더를 추가하면 이름과 아이콘을 가진 세로 탭으로 남고, 탭을
  누를 때 Explorer가 정확히 그 폴더 하나로 바뀐다.
- 같은 경로를 다시 선택하면 별도 폴더 탭이 추가된다. 첫 탭은 폴더 이름을 그대로
  쓰고, 같은 경로의 다음 탭부터는 `폴더 이름 (2)`, `폴더 이름 (3)`처럼 `(N)` 접미사로
  구별된다. 같은 경로의 탭도 각각 Explorer 상태를 가진다.
- 탭을 닫고, 순서를 바꾸고, 실제 경로와 다른 표시 별칭을 정한 결과가 화면과 다음
  실행 뒤에 모두 유지된다.
- 화면에 보이는 Folder Tabs 헤더 제목은 `FOLDERS`이며, `Add Folder`, `Rename Folder Tab`
  순서의 두 아이콘만 있다. Add는 `Ctrl+O`와 같은 폴더 추가 동작이고, Rename은 활성
  탭이 없으면 비활성화된다.
- 폴더 탭을 클릭하면 활성 표시가 그 탭으로 옮겨지고, 세로 드래그로 순서를 바꿀 때
  놓을 위치가 보인다. 각 탭의 hover `×`는 탭 등록만 제거하며 실제 폴더와 파일은
  건드리지 않는다.
- 활성 탭을 닫으면 바로 아래 탭이, 아래가 없으면 바로 위 탭이 활성이 된다. 마지막
  탭까지 닫으면 활성 탭이 없고 Explorer는 폴더를 열기 전의 빈 상태로 돌아간다.
- 폴더를 오간 뒤에도 각 폴더의 Explorer 펼침·선택·스크롤 상태가 복원된다.
- 앱을 다시 열면 등록 폴더, 순서, 별칭, 마지막 활성 탭과 Explorer 상태가 복원된다.
  이 복원이 v0.2의 "마지막 폴더 하나를 다시 연다"를 대신하며, 최근 폴더 목록은
  경로를 다시 찾는 수단으로 그대로 남는다.
- Folder Tabs 레일을 감추거나 다시 보여도 등록 폴더·탭 순서·별칭·활성 상태·Explorer
  상태가 유지된다. Explorer를 감춘 상태에서 폴더 탭을 선택하면 Explorer가 자동으로
  다시 보이고 선택한 폴더의 트리가 나타난다.
- 삭제되거나 이동한 경로의 탭은 자동으로 사라지지 않고 오류 상태가 보이며, 사용자가
  새 경로를 지정하거나 탭을 닫을 수 있다.
- `Workspace per Folder`는 기본으로 적용되며, 폴더 탭마다 에디터 탭과 분할 화면을 따로
  보존해 전환한다. 이 설정을 해제하면 모든 폴더가 하나의 에디터 레이아웃을 공유한다.
- 설정을 바꿔도 현재 실행 중의 에디터 상태가 버려지지 않으며, 폴더별 에디터 상태는
  앱 재시작 후 복원되지 않고 빈 에디터로 시작한다.
- 두 호스트에서 위 결과가 같고, 기존 Activity Bar의 전역 영역 제어 동작이 바뀌지
  않는다.
