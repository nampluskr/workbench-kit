## 미해결 · 남은 위험

- 150% 확대처럼 CSS 뷰포트가 640×480 창보다 더 작아지는 경우는 이 검증 범위 밖이다.
- `verify:dist`는 Electron·pywebview가 같은 빌드 파일 집합과 해시를 읽는 것을 확인했다. About의 실제 무스크롤 레이아웃 측정은 Electron에서 수행했다.
