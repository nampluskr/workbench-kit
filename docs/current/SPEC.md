# SPEC — workbench-kit

## 1. 기능 요구사항

모두 **133건**이다. `refs/scenarios.md`의 87개 항목이 FR 번호를 달고 그대로 옮겨
왔고(시나리오의 절 기호 A ~ M을 FR 번호에 살려 역참조가 끊기지 않게 했다), 여기에
시나리오에는 없지만 결정이 이미 결과를 정해 둔 46건을 `†`로 표시해 더했다.
그중 10건(FR-A20 ~ A24 · FR-N6b · FR-N6c · FR-I9 ~ I11)은 D-9와
`refs/vscode-reuse-plan.md`가 "둔다"고 한 탐색기 뷰 제목줄이 시나리오로 내려오지
않은 것을 D-30 · D-31로 메운 것이다. 다시 3건(FR-N10a · FR-N10b · FR-R1a)은
D-21과 D-19가 뜻만 밝히고 앱이 부를 자리를 정하지 않은 것을 D-32와 D-19 보강으로
메운 것이다.

**공통 판정 규칙** — 아래 모든 FR은 **Electron 갈래와 pywebview 갈래에서 각각**
판정하며, 두 갈래의 결과가 다른 항목이 하나도 없어야 한다(FR-H1). 판정 방법에
"두 갈래에서"를 매 행마다 반복해 적지 않는다.
