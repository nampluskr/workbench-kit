# 다음 버전으로 미룬 것

> 참조 메모 · 작성일: 2026-09-08 · 대상 버전 v0.1
>
> **버전 문서가 아니다.** `docs/current/`가 아니라 `refs/`에 두는 이유는, 버전을 마감할
> 때 `docs/current/`만 `docs/history/vX.Y/`로 복사되고 `docs/refs/`는 그 자리에
> 남기 때문이다(`project-workflow/docs/VERSIONING.md` 5절). 버전을 넘어 살아야 하는
> 메모라 여기 둔다.
>
> 파일명에 버전 번호를 넣지 않는다. major·minor는 사람이 정하므로(AGENTS.md), 이
> 파일 하나를 계속 비우고 채운다.

## 이 문서의 자리

| 무엇 | 어디 |
| --- | --- |
| **이번 버전에서 하지 않는다**는 판정용 한 줄 | `SPEC.md` 4절 `X-n` |
| **왜 미뤘고 다음에 어떻게 풀 것인가** | 이 문서 |
| 착수 뒤 계획 밖으로 붙은 것 | `docs/current/PROGRESS.md` (`WORKFLOW.md` 7절 17번) |
| 다음 버전 기획 때 뒤를 보는 자리 | 다음 `BRIEF.md`의 3번 블럭 "이전 버전에서 아쉬웠던 것" |

`SPEC.md` 4절의 미구현 대상은 **영구 배제**(X-2 VS Code 복제)와 **다음 버전 후보**가
섞여 있다. 후보인 것만 이 문서에 `N-n`으로 적고, `X-n`이 여기를 가리킨다.

**여기 적는 것과 안 적는 것** — 적는 것은 "다음 버전에 하면 좋겠다"까지 판단이 선
것이다. 아직 하고 싶은지도 모르는 것은 적지 않는다. 이 문서가 길어지면 다음 버전
`BRIEF`가 이 목록을 소화하는 일이 되어 버린다.

## N-1. 앱 보기 안에서 쓸 편집기 위젯을 빌려준다

**무엇** — 지금 monaco는 **탭 하나 = 편집기 하나**로만 열린다(`FR-P1` ~ `FR-P6`).
앱이 자기 보기 **안에** 편집기를 여러 개 두는 형태 — 노트북의 셀마다 편집기 —
가 안 된다. 껍데기가 편집기 위젯을 하나씩 빌려주고 거두는 표면이 필요하다.

**왜 v0.1에 안 넣었나** — 검증 앱 셋(마크다운 뷰어·파일 커맨터·멀티터미널) 중
어느 것도 요구하지 않는다. 요구하는 것은 확장 후보인 주피터 노트북 하나뿐이다.
지금 넣으면 monaco 표면 설계(수명·포커스·테마 전파·여러 인스턴스의 키 배분)가
따라붙어 MVP가 늦어진다.

**v0.1이 이 길을 막지 않는다** — `FR-P6`의 판정은 "**앱 쪽 의존성에 monaco가
0건**"이다. 껍데기가 자기 표면으로 위젯을 빌려주면 앱은 monaco에 직접 의존하지
않으므로 이 판정이 그대로 성립한다. **v0.2에서 `SPEC`을 뒤집지 않고 더하기만 하면
된다.** 막히는 것은 앱이 monaco를 **직접 가져오는** 길뿐인데, 그 길은 애초에 택하지
않는다.

**v0.2에서 정해야 할 것** — 빌린 위젯의 수명이 탭 수명(`FR-E1` ~ `FR-E5`)과 어떻게
겹치나 · 여러 인스턴스 중 어디가 키를 받나(`FR-I6`) · 세 색 테마가 어떻게 전파되나 ·
빌려준 것을 앱이 안 거두면 어떻게 되나.

**관련** — `SPEC.md` X-22 · `DECISIONS.md` D-18 · `PLAN.md` Phase 6

## 확장 후보 앱 — 무엇이 이미 성립하나

v0.1 껍데기가 받아낼 수 있는지 대조한 결과다. 기존 검증 앱 셋(마크다운 뷰어·파일
커맨터·멀티터미널)은 `INTENT.md` 7절에 있고, 아래는 그 뒤에 나온 후보다.

| 앱 | 껍데기가 이미 주는 것 | 남은 것 |
| --- | --- | --- |
| 마크다운 에디터 | 파일 프리셋 · monaco · ●와 저장 확인 창 · 옆 칸에 열기로 편집/미리보기 나란히 · File에 저장 항목 더하기 | 없다 |
| 텍스트 에디터 | 위와 같음. 껍데기 + 기본 보기만으로 거의 성립 | 없다 |
| PDF 뷰어 | 리소스 종류 등록 · 탭 안 키 위임 · 우클릭 항목 | 없다 |
| 주피터 노트북 (실행) | pywebview 갈래 · 살아 있는 보기의 수명(터미널과 같은 자리) · 앱이 하단 바에 올리는 커널 상태·진행 | **N-1** |
| 마인드맵 | 리소스 종류 등록 · 앱 전용 키 · 우클릭 메뉴 · 저장 확인 창 · File·뷰 제목줄 확장 | 없다 |

**두 축은 그대로다.** 다섯 모두 `INTENT.md` 3절의 파일 축 안에 들어가고, 새 축이나
새 탭 규칙을 요구하지 않는다. **INTENT는 고치지 않는다.**

근거를 찾는 자리다.
